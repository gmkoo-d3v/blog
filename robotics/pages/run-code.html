내 PC에서 예제 실행하기

시범 보기 → 따라 하기 → 이유 이해 → 선택적 확인

예제 파일은 이 컴퓨터의 C:\code\src\robo\vol3\ 아래에 있습니다. 실행할 때 지켜야 할 것은 하나입니다. MuJoCo가 들어 있는 파이썬, 즉 C:\code\src\robo\.venv\Scripts\python.exe로 돌리는 것입니다.

이 글의 명령과 출력은 이 컴퓨터(윈도, MuJoCo 3.17.0, 파이썬 3.12.3)에서 실행해 확인했습니다.

폴더 네 개

폴더 (vol3\ 아래)내용예제 파일이 노트에서
01-what-is-a-robot1장 로봇이란b01–b261일차 1~6번 글
02-frames-rotations2장 좌표계와 회전b01–b261일차 7~12번 글
03-kinematics3장 기구학b01–b252일차 기구학 글
04-mujoco-basics4장 MuJoCo 입문b01–b24, 보충 v01–v052일차 MuJoCo 글

파일 이름의 b##는 장 안의 예제 번호라서 장마다 b01부터 다시 시작합니다. v##는 04 폴더에만 있는 보충 예제입니다.

실행하는 세 가지 방법

같은 예제(04-mujoco-basics\b01_hello.py)를 세 곳에서 돌렸더니 마지막 줄이 모두 1.0초: 각도 -75.3도로 같았습니다. 편한 방법을 고르면 됩니다.

# 1) 폴더로 들어가서 실행
cd C:\code\src\robo\vol3\04-mujoco-basics
..\..\.venv\Scripts\python.exe b01_hello.py

# 2) 어느 폴더에서든 전체 경로로 실행
C:\code\src\robo\.venv\Scripts\python.exe C:\code\src\robo\vol3\04-mujoco-basics\b01_hello.py

# 3) 환경을 지정해서 실행 (uv가 설치되어 있을 때)
cd C:\code\src\robo
uv run --no-sync python vol3\04-mujoco-basics\b01_hello.py

1일차 글에 적힌 python 01-what-is-a-robot\b13_period.py 같은 줄은 vol3 폴더에서 치는 명령입니다. 그 줄의 python을 위의 .venv 파이썬 경로로 바꾸어 실행하세요. vol3에서 01-what-is-a-robot\b15_env_check.py를 이 방식으로 돌리면 MuJoCo : 3.17.0이 나옵니다.

그냥 python이면 MuJoCo를 못 찾습니다

PATH에 걸린 파이썬(C:\Users\user\AppData\Local\Programs\Python\Python312\python.exe)으로 import mujoco를 하니 ModuleNotFoundError: No module named 'mujoco'가 나왔습니다. 두 파이썬은 버전이 같아도 다른 프로그램입니다. 환경을 켜 두고 python만 치고 싶다면 C:\code\src\robo\.venv\Scripts\Activate.ps1을 먼저 실행하세요(이 컴퓨터에서 활성화 스크립트가 있는 것만 확인했고 실행해 보지는 않았습니다).

알아 두면 덜 헤매는 세 가지

  • 저장되는 파일은 “지금 있는 폴더”에 생깁니다. 임시 폴더에서 b12_frames.py를 돌렸더니 bounce.gif와 bounce_frames.png가 그 폴더에 만들어졌습니다. 예제 폴더를 어지럽히기 싫으면 다른 폴더에서 전체 경로로 실행하세요.
  • 한글 글꼴 경고가 보일 수 있습니다. 예제의 그림도구.py는 5행에서 D2Coding 글꼴을 지정합니다. 이 컴퓨터에는 그 글꼴이 있어서 b12_frames.py가 경고 없이 돌았습니다. 글꼴이 없는 컴퓨터에서는 findfont: Font family '…' not found. 꼴의 경고가 여러 줄 나오고 그림 속 한글이 □로 보입니다. 해결은 MuJoCo 시작하기의 글꼴 항목에 있습니다.
  • 예제 폴더 밖에서는 도우미 파일을 불러올 수 없습니다. 팔장면.py 같은 도우미 파일은 04 폴더 안에 있습니다. 예제를 경로째로 실행하면 어느 폴더에서든 잘 돌지만(b22_arm_check.py를 임시 폴더에서 돌려 확인), 다른 폴더에서 직접 쓴 코드에서 from 팔장면 import XML을 하면 ModuleNotFoundError: No module named '팔장면'이 납니다. 내 코드를 쓸 때는 04 폴더 안에 두세요.

창이 뜨는 예제(v01_viewer_pendulum.py)는 화면이 있는 컴퓨터에서만 의미가 있습니다. 창을 읽는 법은 MuJoCo 시작하기에 있습니다.
