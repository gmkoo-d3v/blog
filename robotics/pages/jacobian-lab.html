첫 장면: 속도 화살표 보기

팔은 XY 평면에 있고 파랑은 어깨가 만드는 손끝 속도, 주황은 팔꿈치의 기여, 초록은 두 기여의 합입니다. 화살표는 미래 위치가 아니라 지금 순간의 속도입니다.

처음으로를 누르고 ① 어깨만 돌리기를 누르면 곧게 편 팔에서 어깨 속도 1rad/s, 팔꿈치 속도 0일 때 손끝은 위로 0.7m/s의 순간 속도를 가집니다. 길이 0.4+0.3=0.7m인 팔 전체가 어깨 주위를 돌기 때문입니다. 현재 자세 J의 첫 열 (0,0.7)에 속도 1을 곱한 결과와 같습니다. 0.1초 버튼은 실제 각도를 조금 바꿔 비교합니다.

마우스 드래그: 회전 · 휠: 확대 · 오른쪽 드래그: 이동. 휴대폰은 위 체크를 켜면 한 손가락 회전·두 손가락 확대/이동, 끄면 페이지 스크롤입니다. 팔은 XY 평면에서 움직이고 카메라만 공간을 돌아봅니다. 앞·옆에서는 평면을 옆으로 보기 때문에 팔이 겹쳐 보일 수 있습니다.

파랑: 위팔·어깨 기여 / 주황: 팔꿈치 기여 / 초록: 합계 속도. 화살표는 현재 순간 속도이며 손끝의 미래 위치가 아닙니다.

버튼을 누르면 현재 관절 속도로 0.1초 움직인 실제 자세를 계산합니다.

지금 팔의 자세 q

슬라이더는 도(°), Python의 q는 라디안입니다. q는 위치를 정하는 각도이고, 관절 속도 q̇와 다릅니다.

다음 단계: 실제 관절 속도를 넣으면?

단위는 rad/s. 음수는 반대 방향입니다. 각도 q를 고정하고 속도만 바꾸면 J는 그대로이고 화살표가 바뀝니다.

두 관절 기여는 방향을 포함한 벡터로 더합니다. 각 화살표의 길이를 그냥 더한 값이 속력이 되는 것은 아닙니다.

교안의 Python 코드와 지금 숫자를 연결하기

위 J의 네 칸 중 하나를 누르면 반환 배열의 같은 칸이 강조됩니다. 원본 함수와 같은 순서로 q → 삼각함수 → 네 칸을 계산합니다.

def 야코비안2(q) -> np.ndarray:
    s1, c1 = np.sin(q[0]), np.cos(q[0])
    s12, c12 = np.sin(q[0] + q[1]), np.cos(q[0] + q[1])
    return np.array([[-위팔 * s1 - 아래팔 * s12, -아래팔 * s12],
                     [위팔 * c1 + 아래팔 * c12, 아래팔 * c12]])

J @ qdot는 각 행의 두 곱을 더합니다. J만 반환했다고 실제 속도가 결정되는 것은 아닙니다.

0.1초 근사와 실제 계산은 왜 조금 다를까?

초기 순간의 접선 속도로 p + v × 0.1을 계산하면 직선 근사입니다. 실제로는 q새값 = q + qdot × 0.1을 만든 다음 FK를 다시 계산합니다. 팔이 돌면서 J가 변하므로 두 점은 조금 다를 수 있습니다.

이 실험은 관절 제한이 없는 운동학 모델입니다. 180°를 넘으면 같은 자세의 음수 각도로 표시할 뿐, 속도를 잘라 내지 않습니다. 모든 화면 숫자는 보기 좋게 반올림합니다.
