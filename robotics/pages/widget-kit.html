방금 본 것 확인하기 (선택)

관절마다 목표 각도를 줄 뿐, 손끝의 길은 아무도 정하지 않았습니다. 팔꿈치가 어깨보다 먼저 도착해서 손끝이 휩니다.

네 점 모두 도착했지만 상자는 그대로입니다. 마지막 목표만 (60°, 0°)으로 바꾸면 같은 코드가 상자를 쳐서 떨어뜨립니다. 목표 도착과 작업 성공은 다릅니다.

이 그림의 코드는 수업 형태의 b23(점 4개, 출력 4줄)을 생성기 안에 사본으로 두고 오너 폴더에서 돌린 것입니다. 지금 오너가 고치고 있는 b23_arm_points.py(뷰어를 열고 끝없이 되풀이)와 줄 번호가 다를 수 있습니다.

“처음부터 보기”를 누르고 빨간 공이 주황 공에 다가가는 과정을 보세요.

시작 (90°, −30°)에서 남은 거리: 0.502 → 0.743 → 0.265 → 0.0644 → 0.00542 → 4.95×10⁻⁵ → 4.99×10⁻⁹ → 5.55×10⁻¹⁷ m, 도착 (59.5°, −68.0°).

방금 본 것 확인하기 (선택)

한 바퀴는 넷입니다: 남은 거리를 재고(12행), 충분히 작으면 멈추고(14행), 아니면 그 화살표 쪽으로 각도를 고칩니다(16행). 고치는 방향은 지금 자세에서만 맞기 때문에 첫 걸음은 지나쳤고, 새 자세에서 다시 재자 남은 거리가 빠르게 줄었습니다.

출발 자세를 (0°, 30°)로 바꾸면 같은 목표의 다른 자세 (2.5°, 68.0°)에 닿습니다. 어느 자세에 닿을지는 출발 자세가 정합니다.

원래 글 1,721자 (p.23–24, 공백 뺀 글자)지금 글 259자 (+ 안내 장면 글)학습자가 하는 일: 안내 6장면 보기 → 한 줄씩 넘기며 팔·화살표·그래프 보기 → 다른 출발 자세 겹쳐 보기 → 코드 줄을 눌러 그 줄이 실행된 순간으로

파일의 목표는 (0.4, 0.3)이고 7·8행 중 8행이 켜져 있습니다. 이 그림은 수업처럼 5행을 0.5로 바꾸고 7행을 켠 실행입니다(메모리에서만 바꿈, 줄 번호 그대로).

데이터 파일 두 가지


숫자 파일은 생성기가 만들고(손으로 고치지 않음), 보기 파일은 사람이 씁니다. 무대의 data-src에 둘을 차례로 적으면 합쳐집니다.


// content/kit-data/b23-arm.js  (생성: make_kit_data.py가 수업 형태 b23을 오너 폴더에서 실행해 기록)
Kit.data("b23-arm", { file, source, code: [소스 줄...], lines: {ctrl, step, print},
  runs: { b23: { label, change, cols: { t:[s], S:[°], E:[°], TS, TE, TX:[mm], TY, BX, BY, BZ, QW..QZ, line, out },
                 events: [{t, label}], out: [찍힌 줄...], targets, goals, hold } , b23x: {...} } });

// content/kit-data/b23-arm-view.js  (사람이 씀: 무엇을 어떻게 그리고 어떻게 안내할지)
Kit.data('b23-arm-view', {
  fields:   { S: {label:'어깨 각도 (파란 막대)', unit:'°', digits:1, color:'#3380e6'}, off: {label:'…', value: c => …} },
  scenes3d: { arm: { camera, target, items:[ {type:'cuboid', name:'table', …}, {type:'arm', names:['upper','lower'], tip:'tip', …} ] } },
  plots:    { joints: { x:'t', y:['S','E',{col:'TS', dash:true, step:true}], ylabel:'관절 각도 (°)' } },
  tours:    { main: { intro, start:{t:4}, beats:[ {t:0.01, focus:['upper','lower','tip'], callout:{at3, text}, caption:'…'}, … ], after } },
  recaps:   { bend: { prompt:'방금 본 것: …?', options:[…], show: 3 } },
  tables, codes, lineNotes });
