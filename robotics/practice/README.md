# 야코비안 따라하기: 세 번 실행해서 확인하기

`practice/jacobian_followalong.py`는 교안 PDF 21쪽 / 교과서 3.5절의 2링크 팔을
`두링크.py`(순기구학2·야코비안2)와 `b13_velocity.py`(속도 예제)에서 그대로 옮긴
NumPy 연습 파일입니다. 링크는 위팔 0.4 m, 아래팔 0.3 m로 고정되어 있습니다.
실제 로봇이나 시뮬레이터를 움직이지 않고 숫자만 계산합니다.

## 먼저 답: 세 번 실행하면 이렇게 나옵니다

| 실행 | 자세 q | 관절 속도 qdot | J (m/rad) | 손끝 속도 v (m/s) | 속력 \|v\| |
|---|---|---|---|---|---|
| 기본 | 30°, 45° | 0.5, -0.2 | [[-0.489778, -0.289778], [0.424056, 0.077646]] | [-0.186933, +0.196499] | 0.271212 |
| `--dq 0.5 0` | 30°, 45° (그대로) | 0.5, 0 (팔꿈치만 0) | 위와 **완전히 같음** | [-0.244889, +0.212028] | 0.323923 |
| `--q 0 0` | 0°, 0° | 0.5, -0.2 (그대로) | [[0, 0], [0.7, 0.3]] | [0, +0.290000] | 0.290000 |

한 줄 요약: **자세 q를 바꾸면 J가 바뀌고, 속도 qdot만 바꾸면 J는 그대로입니다.**
속도를 0으로 만들면 그 열의 기여만 0이 되고, J의 칸은 남아 있습니다.

## 실행 전 확인 (설치하지 않습니다)

Python과 NumPy가 준비되어 있는지 확인합니다.

```powershell
python --version
python -c "import numpy; print(numpy.__version__)"
```

두 명령이 버전을 출력하면 추가 설치가 필요 없습니다. 출력되지 않으면 여기서 멈추고
환경을 먼저 확인하세요. 이 안내는 패키지 설치를 요구하지 않습니다.

## 0단계: 연습 폴더로 이동

터미널에서 내려받은 `robotics` 폴더로 이동합니다. 아래 명령은 그 폴더에서 실행합니다.

## 1단계: 기본값 그대로 - 기준 만들기

```powershell
python practice\jacobian_followalong.py
```

실제 출력 중 숫자 부분(위아래 안내 줄은 생략):

```text
[1] 야코비안 J - 자세 q만으로 정해지는 영향표 (m/rad)
                 어깨 열       팔꿈치 열
      x 행     -0.489777748     -0.289777748
      y 행     +0.424055875     +0.077645714
...
[2] 열별 기여 - 각 열에 그 관절의 실제 속도를 곱한 것
  어깨   [-0.489778, +0.424056] × +0.500000 = [-0.244889, +0.212028] m/s
  팔꿈치 [-0.289778, +0.077646] × -0.200000 = [+0.057956, -0.015529] m/s
...
[3] 합산 = 이 순간의 손끝 속도 v = J @ qdot
  vx = -0.186933 m/s  (왼쪽 방향)
  vy = +0.196499 m/s  (위쪽 방향)
  v  = [-0.186933, +0.196499] m/s
  속력 |v| = 0.271212 m/s
...
[4] 유한차분 '평균' 속도 - 0.001s 동안 순기구학으로 잰 위치 차이
  각도 변화량 qdot·dt = [+0.000500, -0.000200] rad
  손끝 위치: [0.424055875, 0.489777748] m
          → [0.423868895, 0.489974209] m
  (새손끝 - 손끝)/dt = [-0.186980, +0.196461] m/s  · |평균| = 0.271216 m/s
  J@qdot와의 차이 = [+0.000047, +0.000038] m/s  (최대 4.68e-05)
```

이 실행의 J와 v를 기준으로 삼습니다. `[4]`의 값이 `[3]`과 미세하게 다른 이유는
`[3]`이 **시작 순간**의 속도이고 `[4]`는 0.001초 동안의 **평균**이기 때문입니다.

## 2단계: 팔꿈치 속도만 0으로 - J가 그대로인지 보기

각도는 건드리지 않고 `--dq`의 둘째 숫자만 0으로 바꿉니다.

```powershell
python practice\jacobian_followalong.py --dq 0.5 0
```

```text
[1] 야코비안 J - 자세 q만으로 정해지는 영향표 (m/rad)
                 어깨 열       팔꿈치 열
      x 행     -0.489777748     -0.289777748
      y 행     +0.424055875     +0.077645714
...
[2] 열별 기여 - 각 열에 그 관절의 실제 속도를 곱한 것
  어깨   [-0.489778, +0.424056] × +0.500000 = [-0.244889, +0.212028] m/s
  팔꿈치 [-0.289778, +0.077646] × +0.000000 = [+0.000000, +0.000000] m/s
...
[3] 합산 = 이 순간의 손끝 속도 v = J @ qdot
  v  = [-0.244889, +0.212028] m/s
  속력 |v| = 0.323923 m/s
...
[4] 유한차분 '평균' 속도 - 0.001s 동안 순기구학으로 잰 위치 차이
  (새손끝 - 손끝)/dt = [-0.244942, +0.211967] m/s  · |평균| = 0.323923 m/s
```

- **그대로:** q, J의 네 칸, 어깨 열의 기여, dt, 링크 길이.
- **바뀐 것:** 팔꿈치 열의 기여가 [0, 0]이 되고, v와 속력이 바뀝니다.
- 속력이 0.2712 → 0.3239로 **커졌습니다.** 원래는 팔꿈치의 음의 회전이 어깨가 만드는
  왼쪽·위쪽 이동을 일부 상쇄하고 있었기 때문입니다. 상쇄가 사라지면 남는 속도가 커집니다.

## 3단계: 각도만 0으로 - J가 다시 계산되는지 보기

이번에는 속도는 그대로 두고 `--q`만 0, 0으로 바꿉니다.

```powershell
python practice\jacobian_followalong.py --q 0 0
```

```text
[1] 야코비안 J - 자세 q만으로 정해지는 영향표 (m/rad)
                 어깨 열       팔꿈치 열
      x 행     +0.000000000     +0.000000000
      y 행     +0.700000000     +0.300000000
...
[2] 열별 기여 - 각 열에 그 관절의 실제 속도를 곱한 것
  어깨   [+0.000000, +0.700000] × +0.500000 = [+0.000000, +0.350000] m/s
  팔꿈치 [+0.000000, +0.300000] × -0.200000 = [+0.000000, -0.060000] m/s
...
[3] 합산 = 이 순간의 손끝 속도 v = J @ qdot
  v  = [+0.000000, +0.290000] m/s
  속력 |v| = 0.290000 m/s
...
[4] 유한차분 '평균' 속도 - 0.001s 동안 순기구학으로 잰 위치 차이
  (새손끝 - 손끝)/dt = [-0.000063, +0.290000] m/s  · |평균| = 0.290000 m/s
```

- **그대로:** qdot(0.5, -0.2), dt, 링크 길이.
- **바뀐 것:** q가 바뀌었으므로 J를 다시 계산합니다. x 행이 0이 된 것은 팔이 x축에
  정확히 누워 있어 이 순간 손끝의 접선 방향이 위쪽뿐이기 때문입니다.
- x 속도가 0인 것은 **이 순간**의 이야기입니다. 조금이라도 돌면 x도 변합니다.
  `[4]`의 x 성분 -0.000063 m/s가 그 흔적입니다.

## 직접 숫자 하나 바꿔 보기

파일 맨 위의 학습자용 기본값만 고치면 됩니다. 링크 길이는 교안과 맞추기 위해 고정입니다.

```python
Q_DEG_DEFAULT = (30.0, 45.0)   # 어깨, 팔꿈치 각도 [deg]  ← 여기 숫자를 바꿔도 됩니다
DQ_DEFAULT = (0.5, -0.2)       # 어깨, 팔꿈치 각속도 [rad/s]
DT_DEFAULT = 0.001             # 유한차분 간격 [s]
```

예를 들어 `Q_DEG_DEFAULT`의 30.0을 60.0으로 저장한 뒤 `--` 없이 다시 실행해 보세요.
J의 네 칸이 바뀌는지, `[2]`의 기여와 `[3]`의 v가 함께 바뀌는지 확인하면 됩니다.
`--q`/`--dq`를 주면 파일의 기본값 대신 그 값이 쓰입니다.

## 읽을 때 주의

- J는 m/rad(관절 1rad당 손끝 몇 m), v는 m/s입니다. J에 qdot을 곱해야 속도가 됩니다.
- `[3]`은 순간 속도, `[4]`는 짧은 구간의 평균입니다. 큰 dt에서는 두 값이 더 벌어집니다.
- 이 파일은 NumPy 수치 계산만 합니다. 실제 로봇 구동이나 물리 시뮬레이션 결과가 아닙니다.
