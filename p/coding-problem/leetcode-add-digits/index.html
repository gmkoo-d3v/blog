Coding Problem

LeetCode 258 Add Digits 풀이
Digital Root와 mod 9

숫자의 각 자릿수를 한 자리 수가 될 때까지 더하는 문제를 재귀로 먼저 풀고, 왜 (num - 1) % 9 + 1 공식으로 O(1)에 해결되는지 정리한다.

2026-04-26 LeetCode 258 Java, Math, Digital Root
문제 이해 재귀 풀이 mod 복습 왜 9인가 38 mod 9 계산 엣지 케이스 O(1) 풀이 정리

문제 이해

LeetCode 258번 Add Digits는 정수 num의 각 자릿수를 계속 더해서 한 자리 숫자가 될 때까지 반복한 뒤, 그 최종 값을 반환하는 문제다. 

num = 38
38 -> 3 + 8 = 11
11 -> 1 + 1 = 2

answer = 2
목표

먼저 문제 정의 그대로 재귀 풀이를 만든 뒤, 마지막에는 반복문과 재귀 없이 O(1)로 푸는 Digital Root 공식을 사용한다.

재귀 풀이

가장 직관적인 방법은 문제 설명 그대로 구현하는 것이다. 숫자가 한 자리면 그대로 반환하고, 두 자리 이상이면 자릿수 합을 구한 뒤 다시 addDigits를 호출한다. 

class Solution {
    public int addDigits(int num) {
        if (num < 10) {
            return num;
        }

        int sum = 0;

        while (num > 0) {
            sum += num % 10;
            num /= 10;
        }

        return addDigits(sum);
    }
}

실행 흐름은 다음과 같다.

addDigits(38)
-> 3 + 8 = 11
-> addDigits(11)
-> 1 + 1 = 2
-> addDigits(2)
-> 2 반환

이 풀이는 이해하기 쉽지만 Follow-up 조건인 반복문이나 재귀 없이 O(1)로 풀기에는 해당하지 않는다.

mod 복습

mod는 나누고 남은 나머지를 의미한다. 

7 mod 3  = 1
10 mod 3 = 1
9 mod 9  = 0
38 mod 9 = 2

핵심 성질은 A mod N이 항상 0부터 N - 1 사이의 값을 반환한다는 점이다. 따라서 어떤 수를 9로 나누면 나머지는 항상 0~8 사이가 된다.

왜 하필 9인가?

10진법에서는 10, 100, 1000을 모두 9로 나누면 나머지가 1이다. 

10 mod 9   = 1
100 mod 9  = 1
1000 mod 9 = 1

10^n ≡ 1 (mod 9)

≡는 합동(congruent)이라는 뜻이다. 쉽게 말해 mod 9 세계에서는 같은 값으로 취급된다는 의미다.

38 mod 9 계산

38을 자릿수로 분해하면 다음과 같다. 

38 = 3 × 10 + 8

여기에 mod 9를 씌운다.

38 mod 9
= (3 × 10 + 8) mod 9

덧셈과 곱셈에는 mod를 적용할 수 있다. 정확히는 계산 결과에 다시 mod 9를 씌우는 형태로 생각하면 된다. 

(3 × 10 + 8) mod 9
= ((3 × 10) mod 9 + 8 mod 9) mod 9
= ((3 mod 9 × 10 mod 9) mod 9 + 8 mod 9) mod 9

이제 10 mod 9 = 1을 대입한다.

= ((3 × 1) mod 9 + 8) mod 9
= (3 + 8) mod 9
= 11 mod 9
= 2
핵심

38 mod 9는 결국 (3 + 8) mod 9와 같다. 그래서 자릿수를 계속 더해도 mod 9 값은 변하지 않는다.

엣지 케이스

일반적으로는 num % 9로 답을 구할 수 있을 것처럼 보인다. 하지만 두 가지 케이스를 조심해야 한다.

입력 num % 9 실제 정답 설명
0 0 0 그대로 0 반환
9 0 9 9의 배수는 최종값이 9
18 0 9 1 + 8 = 9
38 2 2 일반 케이스

따라서 0은 별도로 처리하고, 나머지는 (num - 1) % 9 + 1 공식을 사용한다.

O(1) 풀이

Digital Root 공식은 다음과 같다. 

num == 0 ? 0 : (num - 1) % 9 + 1

최종 Java 코드는 다음과 같다.

class Solution {
    public int addDigits(int num) {
        if (num == 0) {
            return 0;
        }

        return (num - 1) % 9 + 1;
    }
}

실행 흐름을 확인해 보자.

num = 38
-> (38 - 1) % 9 + 1
-> 37 % 9 + 1
-> 1 + 1
-> 2

num = 9
-> (9 - 1) % 9 + 1
-> 8 % 9 + 1
-> 8 + 1
-> 9

num = 0
-> if문에서 바로 0 반환

정리

  • mod는 나누고 남은 나머지다.
  • 10진법에서 10^n mod 9 = 1이다.
  • 그래서 원래 숫자와 자릿수 합은 mod 9 값이 같다.
  • 재귀 풀이는 문제 정의와 가장 비슷해서 이해하기 쉽다.
  • 최적 풀이는 num == 0 ? 0 : (num - 1) % 9 + 1이다.
  • 시간 복잡도는 O(1), 공간 복잡도도 O(1)이다.
